## 二、实验内容与结果

### Lab 01：天气数据与规则决策

**方法**：用 `numpy` 以固定随机种子模拟 14 天天气数据（降雨概率 `rain_prob`、是否阴天 `cloudy`），保存为 `weather.csv`；再用 `pandas` 逐行读取，按规则进行"是否带伞"决策：

- 降雨概率 > 0.6 → 带伞；
- 0.3 < 降雨概率 ≤ 0.6 且阴天 → 带伞；
- 其余 → 不带伞。

**结果**（见 `lab01/decision_bar.png`）：14 天中**带伞 9 天、不带伞 5 天**。决策结果呈明显分段：03-01~~03-05、03-10~~03-12、03-14 带伞，03-06~03-09、03-13 不带伞，与降雨概率和阴天标记完全对应，验证了规则逻辑的正确性。

**体会**：规则决策透明、可解释、易于调试，是"专家经验编码"的典型方式；但规则阈值需人工设定，面对复杂模式时表达能力有限——这正是引出机器学习方法的动机。

### Lab 02：浅层 vs 深度模型拟合非线性数据

**数据**：`gen_data.py` 生成 x∈[-3,3] 的带噪声非线性（U 形）数据 100 条。

**两个模型对比**（见 `lab02/compare.png`）：

| 模型          | 结构                                   | 训练 MSE                         | 拟合表现                  |
| ----------- | ------------------------------------ | ------------------------------ | --------------------- |
| 线性回归（浅层）    | y = wx + b                           | **0.3888**（w=0.0433, b=0.9840） | 一条近乎水平的直线，完全无法跟踪数据走势  |
| 两层全连接网络（深度） | 1 → 32(ReLU) → 1，Adam，lr=0.01，1000 轮 | **0.0745**                     | 绿色曲线紧贴数据的两个峰和一个谷，拟合良好 |

**分析**：

1. 数据本身是非线性的（U 形曲线），而线性模型的表达空间只有"直线"，无论怎么调参 MSE 都居高不下——这是**模型表达能力（假设空间）的天花板**，不是训练不充分；
2. 神经网络借助**隐藏层 + ReLU 非线性激活**，把多条线性片段"折"成曲线，MSE 降至线性模型的约 1/5；
3. 训练过程中损失从 0.1352 稳定收敛到 0.0745，说明优化器与学习率设置合理。

## 三、遇到的问题与解决

| 问题                                 | 原因                        | 解决                                                                                                                            |
| ---------------------------------- | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| matplotlib 中文显示为方框                 | 默认字体 DejaVu Sans 无中文字形    | `plt.rcParams["font.sans-serif"]=["SimHei"]` 并关闭 `axes.unicode_minus`                                                         |
| `FileNotFoundError: synthetic.csv` | 相对路径按"运行时所在目录"解析，而非脚本目录   | 运行前先 cd 到脚本目录；脚本内加 `os.chdir(os.path.dirname(os.path.abspath(__file__)))`；VS Code 设置 `python.terminal.executeInFileDir: true` |
| F5 调试提示"没有用于调试纯文本的扩展"              | 脚本未加 `.py` 后缀，被当作纯文本      | Python 文件必须以 `.py` 保存                                                                                                         |
| `python --version` 无输出             | 命中了 Windows 商店的空壳别名       | 将真实 Python 目录加入 PATH 最前                                                                                                       |
| `not a git repository`             | 在 Git 安装目录而非仓库目录执行 git 命令 | 先 `cd` 进入仓库文件夹再操作                                                                                                             |

## 四、总结与收获

1. **规则系统 vs 学习系统**：Lab 01 的规则决策可解释但靠人工经验；Lab 02 展示了模型从数据中自动"学"出规律的能力。二者互补，实际系统中常先规则兜底、再模型增强。
2. **模型结构决定能力上限**：线性模型再怎么训练也拟合不了曲线；"深度"的价值在于非线性激活带来的表达能力的质变，MSE 从 0.3888 降到 0.0745 是最直观的证据。
3. **工程细节决定成败**：环境变量、文件编码、相对路径、字体配置等"小事"占用了大量调试时间，养成"保存 .py 后缀、脚本内固定工
4. **版本管理**：所有代码、数据与结果图已通过 Git 提交并推送至 GitHub（main 分支），实现了实验的可追溯与可复现。
